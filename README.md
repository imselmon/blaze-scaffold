# create-blazefw-app

Scaffold a new Blaze project for Cloudflare Workers.

## Features

- **Interactive Setup:** Beautiful CLI prompts to guide you through project creation.
- **Zero Config:** Automatically sets up a fully typed Cloudflare Workers project using the `blazefw` framework.
- **Package Manager Support:** Automatically detects and installs dependencies using your preferred package manager (npm, yarn, pnpm, or bun).
- **Git Initialization:** Automatically initializes a new git repository for your project.
- **Wrangler Ready:** Generates `wrangler.jsonc` pre-configured for your project.

## Usage

```bash
npm create blazefw-app@latest
# or
npx create-blazefw-app@latest
```
